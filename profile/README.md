## Troubleshooting Common Issues

Install issues? Check firewall rules for the management console and confirm the agent registration token is current.  
Performance problems? Exclude backup storage from real-time scanning and schedule scans outside backup windows.  
License/activation? Reissue the licence assignment if the agent shows as unlicensed after a reinstall.  
Compatibility? Update agents and console together to avoid unsupported version pairs.  
Update failures? Review the agent log first, since it usually identifies whether backup or security failed.
